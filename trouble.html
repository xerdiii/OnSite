Signing in

My password is not accepted

Passwords are case sensitive, so check Caps Lock first, then check for a space picked up from a paste. If it still fails, reset it — the reset works even when you cannot remember what the old one was.

I never set a password

Accounts opened before we added passwords do not have one, and accounts opened with Google never needed one. On the sign-in screen, enter your email, then choose Email me a six-digit code instead — or use the Google button if that is how you signed up.

I do not know which email I used

Try the addresses you might have used. A code arriving is how you know which one it is. We cannot list them for you — that would let anyone check whether a particular person has an account here.

The code never arrived

Give it two minutes, then check spam or promotions. If it is still missing, ask for a new one — the old code stops working the moment a new one is sent, so only the newest code in your inbox is live.

Codes also expire on their own after an hour. One you find later will be refused even though it looks right.

It says the code is wrong or expired

Those two cases look identical to us — the server does not tell us which it was, so the message covers both rather than guessing. Check the digits against the newest email first; if they match, send a new code and use that one.

Signing up

It says this email is already registered

You already have an account, which is the good version of this problem. Sign in instead, and reset the password if you do not have it. Nothing you paid for is lost.

The password is refused as too short

Eight characters is the minimum. Length beats cleverness — three ordinary words in a row is both stronger and easier to remember than one word with symbols in it.

The verification code is refused

Six digits, no spaces. If you asked for more than one code, only the last one counts. Ask for a fresh one and use that.

I closed the tab before entering the code

The account exists but the address is not confirmed yet. Start signing up again with the same email and password — you will go straight to the code step, and entering it finishes the job.

Google

Google says it is signing me in to a strange address

That is our authentication provider's own domain, which is what Google shows when it cannot show a friendlier name. It is the right place — nothing is being redirected somewhere it should not be. We are getting it renamed.

I signed up with Google but a password is being asked for

Use the Continue with Google button rather than the email box. A Google account has no password here, because Google holds it instead.

Still stuck?

Tell us the business name and roughly when you ordered. A person reads it and answers — usually the same day.
