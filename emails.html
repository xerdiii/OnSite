Sent at sign-up and sign-in

Subject: Your Xovah verification code

Your verification code is 123456.

It expires in 10 minutes and can only be used once. If you did not request it, ignore this email — nobody can access your account with the code alone.

Implementation note: the code goes in the body only, never in a link or URL. Codes expire and are single-use.
